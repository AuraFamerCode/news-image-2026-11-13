# One Day: 13 November 2026

[![make.fun · news-image-01](https://make.fun/badge/news-image-01.svg)](https://make.fun/bounty/news-image-01)

One 1024×1024 image summing up Friday 13 November 2026's world news: eight stories, one per region and field,
set as a front page — Europe's push into the Ukraine peace talks, the FAA's nationwide ground stop, US drones
downed near Bahrain and Iran's refusal of UN inspections, Nvidia's slide after Jensen Huang's exit, the coming
Trump–Xi–Putin summit at APEC, COP31's climate-finance gap, Delhi's hazardous air, and the UN's hunger warning
for DR Congo.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It copies `entry.png`, the entered image, to the output directory. `main.ts` uses the Node standard library only
and needs no network.
